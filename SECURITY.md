# KUNEE Security

This repository contains sample-only project documentation, not production application code. Do not use it to infer that a product, contract, or security review is ready for public use.

## Reporting a concern

Please report suspected vulnerabilities or accidental exposure privately to [support@kunee.app](mailto:support@kunee.app). Include the affected material, impact, and steps to reproduce where safe. Do not send passwords, seed phrases, private keys, or personal data in a report.

Avoid publicly disclosing an unresolved issue or probing systems without authorization. This document does not promise a response time or establish a security-bounty program.

## Safe handling

- Never commit credentials, private key material, recovery phrases, or real user data.
- Use fabricated values for samples and redact sensitive content before sharing diagnostics.
- Treat on-chain activity as operator-only testing unless an authoritative release notice says otherwise. Contract details belong only in the [deployment record](https://github.com/kuneeapp/kunee-contracts/blob/main/DEPLOYMENTS.md).
